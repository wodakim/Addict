# Prompts d'assets - images

Ce dossier parent centralise les règles pour les sous-dossiers d'images.

## Règles de production
- Générer les assets finaux dans les sous-dossiers spécialisés (ex: `merge-items`).
- Toujours conserver une cohérence d'échelle visuelle entre niveaux d'objets.
- Prévoir des variantes de lumière très proches pour éviter un effet "asset d'un autre jeu".

## Prompt de base à réutiliser
"cozy mobile merge game item icon, stylized 2.5D cartoon, centered object, transparent background, soft ambient occlusion, polished materials, readable silhouette at 64px"

## Negative prompt de base
"photorealism, text, watermark, logo, busy background, low contrast object, blurry edges"
